# Farm-Sim-Site-Rework

A remake of a old website about a fictional farm so i can further learn web and server development

It is based on a website i created as part of my foundation apprenticeship in software development back in my first year of the course in 2025. This is a recreation of that idea but with a larger scope and better design due to what I've learned over the last year.

DEPENDENCIES

- Flask
- NPX
- Python3

HOW TO SET UP (Linux bash)

Step 1: Open the terminal

Step 2: cd <path to the root folder>

Step 3: python3 -m venv <venv name>

Step 4: source <venv name>/bin/activate

Step 5: pip install flask

Step 6: Open and run server.py

Step 7: You are now free to use the website :)

note: The website will work without flask but the imported data for the menu and shop pages will not be present.
